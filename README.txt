BÀI TẬP HTML/CSS - KHÁM PHÁ VIỆT NAM

Tệp:
- index.html
- gallery.html
- food.html
- style.css
- images/ (9 ảnh SVG tự tạo)

Đã triển khai:
1. 3 trang HTML; mỗi trang có ảnh, gallery.html có 6 ảnh.
2. Skip link dùng position:absolute và :focus, chỉ hiện khi focus.
3. Navigation dùng Flexbox và nhiều thuộc tính CSS.
4. Tất cả ảnh có border, padding, border-radius.
5. gallery-grid dùng CSS Grid 3 cột desktop.
6. Header/nav và food-flex dùng Flexbox.
7. Hover trên navigation, gallery và food cards.
8. nth-child(even) thay đổi border-radius của ảnh trong gallery.
9. Có alt text, semantic HTML, focus state, responsive layout.

CÁCH ĐĂNG GITHUB PAGES:
1. Tạo repository mới trên GitHub, ví dụ: html-css-final-project
2. Upload TOÀN BỘ nội dung trong thư mục này (index.html phải nằm ở root repo).
3. Vào Settings > Pages.
4. Build and deployment: Deploy from a branch.
5. Chọn Branch: main, Folder: / (root), bấm Save.
6. Sau vài phút URL thường có dạng:
   https://TEN-TAI-KHOAN.github.io/html-css-final-project/
